# Контракт: синхрон-атом (пилот дождь)

> Путь-2 · дата 2026-07-21 · опора: инвентарь `синхрон_пилот_dozhd.md` + бриф автора  
> Не код. Не алфавит. Только правило, из чего состоит атом и как стыкуются оси.

---

## Определение

**Синхрон-атом** — мельчайший **целый** элемент для будущей сборки любого звука:

| Слой | Что входит | Откуда (природа) |
|------|------------|------------------|
| Звук | полный паспорт **104+оси** на локальном окне вокруг `birth` | анализ эталонного звука пилота |
| Образ | **образ_кусочек** — **частичка мироздания, создающая звук** (для дождя: летящая капля + удар о поверхность), не произвольный 2D-срез кадра | ROI/событие на видео, где видна причина |
| Связь | одно время `t = birth` связывает звук и кадр | см. ось времени |

### Обратимость (жёстко)

Разбивка допустима **только** если из атомов можно **воссоздать обратно**:

```
звук(+кадр) → атомы → синтез/сборка → звук'(+согласованный образ)
```

Критерий смысла: атом — не сжатие «выкинуть лишнее», а **достаточный** элемент алфавита.  
Опора канона: round-trip FD уже доказан на буквах (r≈0.972); для пилота дождь — тот же дух: измеримый возврат, не «похоже на глаз» без метрики.

Алфавит-переводчик и материализация — **после** корпуса таких **обратимых** атомов. В этот контракт не входят как реализация, но входят как требование к качеству нарезки.

Канон: атом = ядро + `params_104` + 5 осей (`СПРАВОЧНИК_104_и_атом.md`). «105» автора = та же полнота паспорта.

## Ось времени

```
frame_i = floor(birth * fps)   # fps видео чистого слоя
t_audio = birth                # секунды на выбранной звуковой оси
```

- `birth` ∈ [0, T_axis), где `T_axis` = длительность **выбранного** звука.  
- Кадры с `frame_i` вне длины `clean_video` — брак, атом не пишем.  
- Пока старт звука и старт видео не выверены кросс-корреляцией:  
  **`alignment = assumed_t0`** (считаем t=0 общим). Это флаг честности, не «уже синхрон».

## Источник звука (пилот дождь) — правило

Факт k1: `dozhd_real.wav` = **2.4 с**; `video_live_02` (+ AAC) = **9.9 с**; клетка span ≈ **2.34 с** ≈ wav; model3d births = **0** (не шкала).

**Режим пилота A (активный):**

| Роль | Файл | Зачем |
|------|------|--------|
| Звук для 104+оси | `данные/клеточки/эталоны/dozhd_real.wav` | совпадает с клеткой; эталон корпуса; не перезаписывать |
| Образ_кусочек | кадр из `данные/стихии_живые/dozhd/clean_video.mp4` | чистый природный слой |
| Живой клип со своим AAC | `video_live_02.mp4` | референс мира; **не** ось 104 в режиме A |

**Режим B (отложен):** пересчитать атомы с родной дорожки `video_live_02` на всю длину 9.9 с — отдельный GATE, не молча.

Пока действует **только A**. Подмена звука без смены режима = запрет.

---

## образ_кусочек

- Берётся из **чистого** слоя (`clean_*`), не из полного кадра с фоном.  
- На атом: ROI/кадр в `frame_i` (минимум: сам кадр + ссылка path/frame_i).  
- Звук эталона и картинка clean стыкуются через `birth` при `alignment=assumed_t0` и `birth < 2.4 с`.

## 1. Определение

**Атом дождя (полный)** =  
`звук_ядро` (уже есть в клетке / протокол v1.0)  
+ **`образ_причины`** (этот контракт)  
связанные одним временем `birth` (или явным `t_sec` на согласованной оси).

**Образ_причины** — не картинка «дождя как пейзажа», а **частичка мироздания, создающая звук**:

1. **flight** — капля в полёте  
2. **impact** — удар о поверхность (+ рябь как следствие удара)

Видео (`video_live_01`) даёт **геометрию и момент** (приблизительно).  
**Вид и масштаб частицы** создаются **законом** (физика капли) и/или рендером частицы ∝ `size` атома — не вырезанием листвы/лужи целиком.

## 2. Обязательные поля атома (слой образа)

Корень атома (минимум для пакета с образом):

| Поле | Тип | Смысл |
|------|-----|--------|
| `id` | str | уникальный id |
| `стихия` | str | `"дождь"` |
| `birth` | float | время на **звуковой** оси клетки / эталона, сек |
| `звук_ядро` | object | ссылка/ядро: `freq`, `amp`, `size`, … или `atom_ref` в клетке |
| `образ_причины` | object | см. §3 — **обязателен** для полной петли |
| `обратимость` | object | флаги §5 |

Ось времени (честность):

| Поле | Смысл |
|------|--------|
| `alignment` | `"axes_decoupled"` (пилот) \| `"event_aac"` \| … — явный режим |
| `t_sec_причина` | время на видео-оси: `birth + t0_geometry_offset` |
| `video_причина` | путь клипа геометрии (пилот: `video_live_01.mp4`) |

**Выверка 2026-08-03:** `dozhd_real` ≠ AAC `video_live_01` (NCC≈0.02) → режим `axes_decoupled`, не `assumed_t0`. См. `alignment_t0_дождь.md`.

## 3. Структура `образ_причины`

```json
{
  "событие": "drop_impact",
  "фаза": "flight | impact | both",
  "геометрия": {
    "video": "данные/стихии_живые/dozhd/video_live_01.mp4",
    "frame_i": 66,
    "t_sec": 2.2022,
    "xy": [809, 486],
    "bbox": [x, y, w, h],
    "track_ref": "отчёты/трек_капли_дождь.json#point | null",
    "роль": "намёк места/момента, не весь пейзаж"
  },
  "закон": {
    "модель": "impulse_shaped | particle_scale | …",
    "r_m": 0.00097,
    "v_ms": 6.56,
    "формула_масштаба": "r_m = (atom.size / size_med) * 1mm",
    "surface": "water"
  },
  "рендер": {
    "тип": "particle_draw",
    "path": "выход/…/частица_….png",
    "запрещено": ["landscape_crop", "willow_canopy", "full_frame_as_atom"]
  },
  "не_есть": "кроп листвы / облака / лужи целиком / HUD-кружки на пейзаже"
}
```

### Правила заполнения

| Можно | Нельзя |
|-------|--------|
| xy / bbox / track точки удара | считать весь кадр 1440×1080 образом атома |
| png/рендер **только капли** (сфера, рябь) | path к clean-пейзажу как финал |
| параметры закона (r, v, surface) | «красивый» оверлей без записи в атом |
| пустой `track_ref`, если геометрия ещё грубая — с флагом `геометрия.approx=true` | притворяться, что кроп = причина |

Минимум для статуса «образ записан в атом»:
- `событие` + `фаза`
- `закон.r_m` (или явная формула из `size`)
- `рендер.path` **или** достаточный `закон` для детерминированного рендера без файла
- `геометрия.t_sec` или связь `birth` → момент

## 4. Воссоздание визуала из атомов (образ')

**Вход:** список атомов с непустым `образ_причины` (+ опционально звук').  
**Выход:** короткий визуальный ряд (кадры или mp4), где:

1. На каждом `birth` / `t_sec_причина` появляется **частица** по `закон` + `рендер` (не чужой пейзаж).  
2. Время согласовано со звуковой сборкой (тот же порядок `birth`).  
3. Фон: нейтральный / тёмный / схема поверхности — **не** подмена образа кропом live-леса.  
   (Живое видео можно показать **сбоку** как калибр геометрии, не как содержимое атома.)

### Приёмка воссоздания (кусок №3 карты)

| Критерий | Смысл |
|----------|--------|
| Полнота | каждый атом пакета с `образ_причины` дал видимую частицу |
| Время | порядок/моменты стыкуются со звуком' |
| Чистота | нет пейзажа-как-атома; глаз видит капли/удары |
| E | автор: ок / почти / мимо |

Метрика «пиксельный PSNR с live_01» — **не** главный критерий (пейзаж ≠ причина).

## 5. Флаги `обратимость`

```json
{
  "звук_в_петле": true,
  "образ_записан_в_атом": false,
  "образ_в_синтезе_визуала": false,
  "геометрия_approx": true,
  "note": "звук v1.0 PASS; образ — по этой карте"
}
```

Полный атом дождя для алфавита — когда **оба**:
- `звук_в_петле` (протокол v1.0),
- `образ_записан_в_атом` + `образ_в_синтезе_визуала`.

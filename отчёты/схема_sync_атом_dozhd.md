# Схема sync-атома — пилот дождь (режим A)

> Вектор B · 2026-07-22 · опора: `контракт_синхрон_атом.md`, раскадровка A  
> Это **схема полей**, не пакет и не экзамен.

---

## Зачем

Обычный атом клетки сейчас несёт **звук/геометрию**, но не несёт **обязательную** привязку к чистому кадру.  
Sync-атом = тот же смысл «мельчайший целый» + явное поле **образ_кусочек**, чтобы образ не жил «сбоку» в папке превью.

---

## Обязательные поля

| Поле | Тип | Смысл | Откуда в пилоте A |
|------|-----|--------|-------------------|
| `id` | str | уникальный id атома | `dozhd_A_{birth}_{frame_i}` или индекс |
| `пилот` | str | эталон | `"dozhd"` |
| `mode` | str | правило звука | `"A"` |
| `alignment` | str | честность оси | `"assumed_t0"` |
| `birth` | float | время на звуковой оси, сек | клетка / раскадровка |
| `frame_i` | int | кадр clean_video | `floor(birth * fps)` |
| `t_frame` | float | frame_i/fps | раскадровка |
| `звук_путь` | str | эталон оси A | `данные/клеточки/эталоны/dozhd_real.wav` |
| `clean_video` | str | источник кадра | `данные/стихии_живые/dozhd/clean_video.mp4` |
| `образ_кусочек` | object | визуальный слой | см. ниже |
| `звук_ядро` | object | звуковой слой (достаточность для сборки) | см. ниже |
| `обратимость` | object | что уже / ещё не в петле | флаги |

### `образ_кусочек` (обязательно) — **УТОЧНЕНИЕ АВТОРА 2026-07-23**

**Было (ошибка пилота B):** path к 2D-кадру/маске clean_video.  
**Нужно:** частичка **мироздания, создающая звук** — не «кусок картинки», а **физическая причина**.

| Стихия | Причина звука (образ_кусочек) |
|--------|-------------------------------|
| Дождь | **летящая капля** + **удар о поверхность** |
| … | аналогично: что в мире бьётся/трётся/срывается → звук |

Поля path/frame_i из clean остаются **возможным носителем**, только если на кадре/в ROI видна именно эта причина (капля, момент удара), а не «любой 2D срез маски».

| Поле | Смысл |
|------|--------|
| `path` | ROI/кадр **причины** (капля/удар), не весь кадр «на всякий» |
| `событие` | напр. `drop_impact` |
| `frame_i` | момент причины |
| `источник` | clean или живое видео — где причина видна |
| `примечание` | «причина звука в мире», не декор |

### `звук_ядро` (обязательно в схеме; наполнение поэтапно)

| Поле | Смысл | Пилот сейчас |
|------|--------|----------------|
| `atom_ref` | ссылка на атом(ы) клетки в этом birth | индекс/список из `etalon_dozhd.json` с тем же birth |
| `freq`, `amp`, `harmonicity`, … | ядро полей клетки | копируются из атома клетки при сборке пакета (B№2) |
| `params_104` | полный паспорт окна | **цель**; в текущей клетке dozhd на атоме часто **нет** готового `params_104` — флаг `params_104: null` + `долг: true` допустим в пилоте, но должен быть явным |

Честно: «105/104 на каждом» — требование цели; пилот B сначала **привязывает образ**, не обязан мгновенно досчитать 104, если их нет в источнике.

### `обратимость` (обязательно флаги)

```json
{
  "звук_в_петле": true,
  "образ_в_синтезе": false,
  "образ_привязан": true,
  "note": "синтез пока только звук; образ участвует в структуре и экзамене наличием кадра"
}
```

Пока `образ_в_синтезе: false` — это **ещё не** полная петля контракта; это шаг B «образ в структуре атома».

## Что входит в синтез звука сейчас / что нет

| Входит | Не входит (пока) |
|--------|------------------|
| поля звука из клетки / синтез_из_атомов | пиксели кадра как вход синтеза |
| birth, freq, amp, crosses клетки | «нарисовать дождь из png» |

Образ в B: **идентичность и экзамен наличия** (path/frame), не генерация картинки из звука.

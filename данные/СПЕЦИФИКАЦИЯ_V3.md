# ТРИНИТИ V3 — СПЕЦИФИКАЦИЯ ПОЗВОНОЧНИКА

> Это не рестарт, а **пере-позвоночник**: каркас строится сразу из чистой
> онтологии, а все проверенные активы **мигрируют 1:1** (не переписываются).
> Документ одновременно служит планом консолидации для V2.

## ЦЕЛЬ (научная, единственная)

Доказуемый, **обратимый** перевод ЛЮБОГО звука ↔ образ через **104 физических
параметра**. Структура, в которой **каждое свойство образа = функция измеренной
величины**, а круг звук → образ → звук замыкается **с измеримой потерей**.
Если круг замыкается — структура несёт информацию, а не украшает. Это и есть
критерий истинности всей работы.

---

## 1. ОНТОЛОГИЯ (одна)

- **Атом** — неизменная частица звукового момента: `freq, amp, harmonicity,
  harmonic_index, time(birth)`. Анатомия атома **не меняется никогда**.
- Координаты звукового вещества (из открытия Гиббса): **ФАЗА × ЯРКОСТЬ**;
  внутри — 104 параметра как детальные оси.
- **Фаза** ∈ {тон, шум, переход} — из гармоничности. Канон: flatness-гейт
  (>0.3 → шум) + HPS `harmonic_ratio`. Пороги: тон >0.6 · шум <0.05 · переход 0.05–0.6.
- **Яркость** = `spectral_centroid` — независимая ось, ортогональная фазе.

## 2. ЗАКОН ОБРАЗА (детерминирован физикой)

Ни одно визуальное свойство не задаётся вручную — всё функция числа:

| Свойство образа | ← Источник (измеренный) |
|---|---|
| позиция / форма | пространственная модель явления (КУДА) |
| **характер движения** | **ФАЗА** (КАК): тон→покой/кристалл, шум→диффузный дрейф, переход→мерцание |
| **направление движения** | **явление** (вниз / вбок / вверх / наружу) |
| цвет | частота (Hz → hue) |
| насыщенность | гармоничность (тембр) / фаза |
| размер | амплитуда |
| рождение | время (onset) |
| свечение / яркость | centroid / loudness |

## 3. ЗАКОН ДВИЖЕНИЯ (свёрнут к фазе — устраняет дубль V2)

- **Фаза = «как ведёт себя вещество»** (физика, измерено).
- **Явление = «куда»** (вектор поля сцены).
- Отдельной ручной «динамики» как самостоятельной системы **нет**; динамика
  явления остаётся только направлением/полем. Три перекрывающихся слоя → два чистых.

## 4. КОНТРАКТ ОБРАТИМОСТИ (научный критерий приёмки)

- Прямой ход: звук → 104 → атомы → образ.
- Обратный ход: образ → атомы → звук (гранулярный/аддитивный синтез).
- **Двойная приёмка** (из находок): тональное — по форме волны (specsim);
  шумовое — по спектральному характеру (корреляция средних спектров).
- На каждый звук фиксируется **round-trip score** (мера потери). Это
  доказательство, что структура несёт информацию.

## 5. КАЛИБРОВКА ЗАКОНОВ (как растёт знание)

- **Зонд-лесенки** (по одному параметру за раз) → измеренные кривые
  «параметр → образ» (не на глаз).
- **Буквица** — независимый экзамен: измеренный закон обязан предсказывать
  образ буквы из её параметров.
- `alphabet.json` **калибруется** данными, не заменяется.

## 6. МИГРАЦИЯ (что переносится 1:1)

Переносим, НЕ переписываем:
- атомизатор / 104-анализатор (`audio-params-104.js`, `atoms_full103.py`, канон фазы);
- корпус атомов (`data/atoms_v1`), 13 явлений-эталонов, 33 буквы, синтетический базис, зонд;
- `буквица_карта.json`, `alphabet.json`, `ЛИНИЯ_манифест.json`, `закономерности_пилот.json`;
- образ-рендер с грамматикой фазы, `образ_в_звук` (round-trip), `сцена_эталон`, композитор «Слово», демо «Фаза→форма».

НЕ мигрирует (выбрасывается):
- ручная слоистость «динамика» как отдельная вселенная (сворачивается в фаза + направление);
- iframe-сцены; дубли приложения Альфа.

## 7. СТРУКТУРА V3 (наука отделена от показа)

- `ядро/` — атом, фаза, 104, round-trip. Чистая физика, без UI.
- `образ/` — рендер: фаза → характер, явление → направление.
- `данные/` — атомы, карты, корпус, лесенки.

## 8. ФРАКТАЛЬНАЯ ОСЬ — ВЛОЖЕННОСТЬ (кандидат в канон · 15 июня 2026)

Новая измеримая ось поверх фазы Гиббса: **глубина взаимовложенных
самоподобных масштабов**, из которых сложен звук. Снимается тем же
единым анализатором, в тех же координатах образа (правило единого тела).

- **FD** — фрактальная размерность Хигучи по форме волны: непрерывный
  спектр буквицы **0.054 → 1.063**, зеркальный гармоничности.
  Чистый тон (У,О,И) внизу → шум (С,Щ) вверху.
- **Δα** — мультифрактальная ширина (MFDFA): отделяет периодическую
  вложенность (тон) от самоподобной шероховатости (шум). На периодике
  Δα срывается (>2) — это не баг, а индикатор «тон ≠ мультифрактал».
- **Смысл вложенности**: тонкая гребёнка гармоник ВНУТРИ медленной
  огибающей формант — мелкий масштаб модулируется крупным.

**Критерий приёмки (выполнен).** Ось FD проходит round-trip
звук → координата → звук: корреляция **r = 0.974**, MAE = 0.043,
семейство сохранено **30/37**. То есть FD — реальное свойство образа,
переносимое и возвращаемое, а не артефакт анализатора. Это отдельный
round-trip ОСИ — не путать с round-trip всего образа (0.717 по фазам, §4).

**Статус:** кандидат в канон. Открыто до полного включения:
(1) число межмасштабного зацепления («взаимо-»); (2) оценщик Δα,
устойчивый на периодике; (3) проверка на нескольких дикторах.

Файлы линзы (`данные/`): `ФРАКТАЛЬНАЯ_ЛИНЗА.md`,
`Тринити_Фрактальная_карта_буквицы.xlsx`, `Тринити_картина_вложенности.png`,
`фрактальная_карта_буквицы.json`, сводка осей `Тринити_оси_статус.xlsx`.

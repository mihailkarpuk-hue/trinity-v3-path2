# ЧАСТЬ A. Метрика «образ ≡ звук»

Идея: образ честен, если то, что **видно**, соответствует тому, что **слышно** —
не «похоже на глаз», а покоординатно измеримо. Три подметрики, каждая — отдельное
число (без усреднения в один котёл, как и в `экзамен_per_key`).

## M1 — цвет ↔ спектр (соответствие по Hz)

Образ красит атом по `freqToHue(freq)` и даёт размер по `amp`. Значит «цветовая
плотность по частоте» = распределение атомов по log-частоте с весом amp. Звук
несёт реальную спектральную энергию. Совпадают ли:

```
EDGES   = 24 log-полосы 60 Гц … 8 кГц
H_образ[b] = Σ amp по атомам в полосе b        (нормировать в сумму 1)
H_звук[b]  = средний по времени |FFT| в полосе b (окно 30 мс, нормировать в 1)
r_цвет = Pearson(H_образ, H_звук)  по 24 полосам
```

Смысл: образ окрашен там, где звук реально звенит. `r_цвет → 1` — честно.

## M2 — пульс ↔ вложенность (временна́я синхронность)

Вложенность звука `N_звук` = средняя попарная корреляция огибающих 6 октавных
полос (уже даёт `оси_звука.nestedness`). Образ показывает вложенность как
**синхронность пульса**: `φ_g = (1−N)·rand`, полоса g пульсирует
`p_g(t)=1+depth/2·sin(2π·rate·t+φ_g)`. Измеримая синхронность образа:

```
N_образ = средняя попарная корреляция 6 пульсов p_g(t)   (усреднить по seeds)
gate M2 : |N_звук − N_образ| ≤ ε      (ε ≈ 0.10)
```

Смысл: синхронность, которую **видно**, воспроизводит сцепку, которую звук
**имеет**. Это замыкание петли на главном инварианте — round-trip вложенности
через образ.

## M3 — форма ↔ поток (опционально)

`onset-огибающая` звука `o(t)` (спектральный поток) vs агрегатное движение облака
`m(t)` (скорость разлёта/сдвига атомов от `динамика`). `r_форма = Pearson(o,m)`.
Направление — категориально (явление), калибруется только **скорость** потока.

## Общий gate (по клетке, без средних)

Клетка проходит «образ≡звук», если `r_цвет ≥ 0.5` **И** `|N_звук−N_образ| ≤ 0.10`.
Отчёт — таблица клетка × подметрика (видно, что и где рвётся), как в per-key.

| О | 0.973 | 0.260 | −0.040 | 0.300 ✗ |

**Что видно:**
- **M1 честен у всех** (0.83–0.99) — цвет=Hz уже соответствует спектру, этот слой
  алгоритма работает без калибровки.
- **M2 различает и вскрыл баг:** при низкой вложенности (О, Ш, С, Ж) образ-синхрон
  проваливается в **минус** (−0.04…−0.12), тогда как звук чуть положителен.
  Причина: формула `φ=(1−N)·rand` при N→0 даёт случайные фазы, а среднее попарной
  корреляции 6 синусов со случайными фазами ≈ **−0.1**, не 0. Нижний полюс не
  откалиброван. Это ровно тот тип константы, что план велит вывести из природы
  (полюс вложенности: `veter` 0.044 … `serdce` 0.84).

Метрика оправдала себя первым же прогоном — не «нарисовано красиво», а показала,
где маппинг врёт.

# ЧАСТЬ B. Нормировки, выведенные из природных полюсов

Источник — `подписи_явлений.json` (13 чистых явлений). Диапазон нормировки каждой
оси = `[min − 5%·span … max + 5%·span]` по корпусу. Это заменяет **угаданные**
диапазоны в `норм(v,a,b)` на измеренные природой. Полюс показывает, какое явление
задаёт край.

| ось | нат. min → max | норм. [a … b] | полюс min → max | куда в коде |
|---|---|---|---|---|
| fd | 0.008 → 1.028 | −0.043 … 1.079 | serdce → pesok | зернистость (образ:99,141) |
| nestedness | 0.044 → 0.84 | 0.004 … 0.880 | veter → serdce | синхрон пульса (пульс) |
| selfsim_r2 | 0.907 → 0.998 | 0.902 … 1.003 | grom → pesok | шаг решётки st (образ:186) |
| mod_depth | 0.206 → 1.61 | 0.136 … 1.680 | dozhd → shagi | размах пульса (пульс) |
| mod_rate | 2.0 → 31.2 Гц | 0.54 … 32.66 | dozhd → vodopad | темп пульса rate (пульс) |
| roughness | 0.519 → 0.876 | 0.501 … 0.894 | serdce → pesok | дрожь/шерох (образ:99,141) |
| spectral_flatness | 0.038 → 0.806 | −0.001 … 0.845 | serdce → pesok | тон↔шум sizeK (образ:95-98) |
| spectral_slope | −1.414 → 0.360 | −1.503 … 0.448 | grom → pesok | тёплый/холодный wt (образ:203) |
| ring_decay | 0.0 → 0.443 | −0.022 … 0.466 | dozhd → kamni | хвост спред/свеч (образ:142) |
| onset_density | 0.04 → 0.133 | 0.035 … 0.138 | kamni → shagi | частота рождения атомов |
| crest_factor | 2.69 → 24.91 | 1.58 … 26.02 | serdce → shagi | вспышка удара (образ:82) |

**Как применять (пример):** `roughness` сейчас идёт в образ сырым (0..1), но
природный диапазон — 0.50…0.88. Значит визуальную дрожь надо считать от
`норм(roughness, 0.50, 0.89)`, иначе полполосы шкалы пустует и разница
гладкого/дрожащего сжата. Так же `fd`, `mod_rate` (реальный темп 2…31 Гц, а дефолт
в коде — фикс 4.0), `crest_factor` (вспышка удара должна масштабироваться от
2.7…25, а не от угаданной `5.0`).

**Физический смысл полюсов (проверка вменяемости):** serdce — низ fd/roughness
(гладкое, периодичное) и верх вложенности («дышит как одно тело»); pesok — верх
fd/шумности; shagi — верх пик-фактора (дискретные удары); grom — самый «низовой»
наклон спектра. Полюса легли по физике — корпус годен как калибратор.

## Порядок применения (замер-первым, ничего не ломая)

1. Начать с **бага M2**: откалибровать формулу пульса так, чтобы `N_образ`
   совпадал с `N_звук` на нижнем полюсе (сдвиг/сжатие фазового разброса, чтобы при
   N→0 корреляция шла к 0, а не к −0.1). Проверять по таблице M2.
2. Заменять нормировки из Части B по одной, каждый раз пере-мерять M1/M2 на
   пилоте — на замороженной копии, не трогая FULL и 5-польный атом.
3. Принять, когда пилот и корпус проходят gate; затем обратный тест
   природа→образ→природа (по инвариантам, тем же per-key способом).

`/tmp/обр_зв_метрика.py` (переносима в `экзамен/` тем же приёмом, что

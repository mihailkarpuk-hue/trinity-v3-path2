## ПРИНЦИП: образ = ФОРМА + ФАКТУРА + ЖИЗНЬ

- **ФОРМА** — куда (модель явления): дождь вниз, огонь вверх. Задаётся явлением.
- **ФАКТУРА** — какой выделки: фрактальные оси (FD, R², вложенность).
- **ЖИЗНЬ** — микро-дрожь, отличающая живое от машинного: jitter, shimmer,
  модуляция, временна́я сцепка. Именно «лишние» параметры (см. открытие 16.06).

Образ оживёт, когда понесёт все три слоя, а не только цвет/размер.

## МАППИНГ: параметр клетки → свойство образа

| Параметр (из 104) | Группа | → Визуальное свойство образа |
|---|---|---|
| `pitch_fundamental`/freq атома | spectral | цвет (Hz → hue) — **есть** |
| `amplitude_rms`/amp атома | temporal | размер атома — **есть** |
| `harmonic_ratio` (harmonicity) | spectral | насыщенность (тон↔шум) — **есть** |
| `spectral_centroid` | spectral | яркость/свечение |
| `attack_time` | temporal | резкость рождения атомов |
| `decay_time`/`ring_decay` | temporal | длина свечения/хвоста |
| `spectral_slope`/`perceptual_warmth` | perceptual | тёплый↔холодный сдвиг цвета |
| **FD (наша ось)** | фактура | зернистость/шероховатость облака |
| **R² (наша ось)** | фактура | рекурсия рисунка (самоподобие) |
| **вложенность (наша ось)** | фактура/жизнь | **иерархия + синхронность пульсации (см. ниже)** |
| **jitter** (дрожь высоты) | жизнь | мелкое дрожание цвета/позиции атомов |
| **shimmer** (мерцание амплитуды) | жизнь | мерцание размера/яркости |
| **mod_depth / mod_rate** | жизнь | глубина и темп общей пульсации образа |
| `onset_density`/`rhythm` | temporal | частота рождения новых атомов |
| `formant_f1..f3` | vocal | сгущения атомов на формантных полосах |

Явление (дождь/огонь/…) → направление движения (форма) — **есть**.

## 🎯 ПЛАН: КАК ПОКАЗАТЬ ВЗАИМОВЛОЖЕННОСТЬ

Вложенность — это **сцепка масштабов во времени** (связаны ли полосы спектра).
Значит и показывать её надо как **временну́ю синхронность**, а не как форму
(помним урок дождя: не путать временно́е с пространственным).

**Реализация в `проекция_образ.js` (скаляр клетки `nestedness` 0..0.94):**

1. **Сгруппировать атомы по масштабу** — по октавным полосам частоты
   (те же 6 полос, что в анализаторе) или по гармоническим семьям.
2. **Дать каждой группе огибающую-пульс** (яркость+размер дышат во времени).
3. **Связать пульсы по вложенности:**
   - высокая вложенность → группы пульсируют **синхронно** (один общий ритм,
     фазы совпадают) — масштабы «дышат вместе», видно единство;
   - низкая вложенность → каждая группа пульсирует **независимо** (случайные
     фазы) — масштабы живут порознь, видно рассыпанность.
   Формула фазы группы g: `φ_g = (1 − nestedness)·random_g` (при nestedness→1
   все φ_g→0, синхрон; при →0 — врозь).
4. **Ритм пульса** берём из `mod_rate` (наша временна́я ось), глубину — из
   `mod_depth`.

Итог: гласная «О» (вложенность ~0.9) — атомы дышат **как одно тело**; шум «С»
(~0.0) — мерцают вразнобой. Незримая сцепка масштабов становится **видимой
синхронностью** — и это честно (временно́е показано временны́м).

**Проверка:** включить звук → у вложенных звуков образ пульсирует слаженно,
у несцеплённых — рябит. Это и есть «увидеть незримо видимое».

# КАК ЗАПУСТИТЬ ОСИ — памятка

> Модули осей Тринити V3. Держать рядом, чтобы не вспоминать каждый раз.

## Файлы
- `Тринити_V3/ядро/оси.py` — считает паспорт осей (FD, R², вложенность, модуляция).
- `Тринити_V3/экзамен/экзамен_осей.py` — round-trip проверка (импортирует оси.py).

## Требования (один раз)
- Python 3 (есть в системе).
- Библиотеки: `pip3 install numpy scipy`
- Декодер аудио (m4a/mp3 → wav). Берётся автоматически:
  - если есть **ffmpeg** — используется он (`ffmpeg -version`; поставить `brew install ffmpeg`);
  - иначе на macOS — встроенный **afconvert** (ничего ставить не нужно).
  - Предупреждение `WavFileWarning: Chunk … skipping` при afconvert — безвредно.

## Запуск (из папки Тринити_V3)
```bash
cd "Тринити Атомы Звука/Тринити_V3"

# Паспорт осей по файлу:
python3 ядро/оси.py "данные/алфавит /О протяжное.m4a"

# Экзамен — round-trip по всей папке:
python3 экзамен/экзамен_осей.py "данные/алфавит "
```

## Критерий «здоров»
- Экзамен по папке: **pearson_r ≈ 0.97** (эталон 0.974), MAE ≈ 0.04.
- Полюса: гласная «О» fd≈0.12 (тон), шум «С» fd≈1.04 — порядок на месте.
Если так — анализатор и контракт целы.

## Подключение в код (одна строка)
```python
import sys; sys.path.insert(0, "ядро")
from оси import оси_звука
паспорт = {"phase": ..., "harmonicity": ..., **оси_звука(x, sr)}
# x — моно-массив, sr — частота дискретизации
```

## Что эмитит оси_звука(x, sr)
```
{fd, selfsim_r2, nestedness, mod_depth, mod_rate}
```

## Память о результатах (эталоны для сверки)
- round-trip FD: r = 0.974, MAE = 0.043, семейство 30/37.
- второй диктор (реальный): r = 0.90, полюса инвариантны ~97%.
- FD ↔ вложенность антикоррелируют: r = −0.57 (разные оси).
- Внимание: вложенность — ВРЕМЕННА́Я сцепка, не пространственная.

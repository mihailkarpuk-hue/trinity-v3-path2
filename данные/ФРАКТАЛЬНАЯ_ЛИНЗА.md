# ФРАКТАЛЬНАЯ ЛИНЗА БУКВИЦЫ — V3

> Сохранено: 15 июня 2026. Линза = аппарат, которым из живого звука вынимаются
> **измеримые координаты вложенности**, доказуемо возвращаемые в звук.
> Это шаг в основной идее: *увязать генеративную интерпретацию с физикой
> для вычленения взаимовложенных фрактальных структур*.

---

## 🎯 ОСНОВНАЯ ИДЕЯ (контекст)

Генеративная интерпретация (атомы / образ) должна не «дорисовывать», а
**восстанавливать структуру, которая доказуемо возвращается в физику**.
Эта линза переносит принцип Тринити (физика → алфавит → образ → обратно)
на задачу: вычленить вложенные самоподобные масштабы, из которых сложен сигнал.

Носитель — звук буквицы (37 живых записей). Звук здесь — **модель** среды
с вложенной структурой, не сама материя (см. «Чего не хватает»).

---

## 🧪 ИСТОЧНИК И МЕТОД

- **Вход:** 37 записей `Тринити_V3/данные/алфавит/*.m4a` (короткие + протяжные).
- **Препроцесс:** ffmpeg → 16 кГц моно, обрезка тишины по огибающей Гильберта.
- **Координаты, снятые с каждой буквы:**
  - спектр (Welch), спектральный центроид;
  - f0 и **гармоничность** (нормированный пик автокорреляции);
  - **фаза** тон / шум / переход (по гармоничности — ось Гиббса);
  - **фрактальная размерность Хигучи (FD)** — шероховатость волны;
  - **мультифрактальная ширина Δα** (MFDFA, спектр сингулярностей);
  - **энергия по 7 октавным масштабам** + число активных масштабов.

Файлы аппарата: `work/full.py`, `work/mfdfa.py`, `work/roundtrip.py` (черновики),
итоговые данные — в JSON ниже.

## ✅ ЧТО ЕСТЬ (доказано)

1. **Ось вложенности FD — непрерывный спектр 0.054 → 1.063**, зеркальный
   гармоничности. Чистый тон (У,О,И протяжные) внизу, шум (С,Щ протяжные) вверху.
2. **Round-trip подтверждён:** ресинтез из спектрального образа → пересчёт FD →
   **корреляция r = 0.974, MAE = 0.043, семейство сохранено 30/37.**
   Значит FD — реальное свойство образа, а не артефакт анализатора.
3. **Δα физически разделяет два типа структуры:** на шуме мерит корректно;
   на чистой периодике срывается (>2) — что само по себе диагностирует
   «тон ≠ мультифрактал, а квазипериодика».
4. **5 семейств по глубине вложенности:**
   - I (FD<0.15) чистый тон — 4 буквы (У,О,И…);
   - II (0.15–0.35) тон+форманты — 17 (ядро);
   - III (0.35–0.60) сложный тон/переход — 9;
   - IV (0.60–0.90) шероховатый переход — 5 (Ж,Ч,Х,Ш,Щ);
   - V (>0.90) шум/мультифрактал — 2 (С прот., Щ прот.).

**Физический смысл взаимовложенности (качественно):** гласная = тонкая
гребёнка гармоник ВНУТРИ медленной огибающей формант — мелкий масштаб
модулируется крупным. От I к V периодичность уступает самоподобной шероховатости.

## ⚠️ ЧЕГО НЕ ХВАТАЕТ (честно)

1. **Мост к материи не наведён.** Всё — про звук. Перенос на материю
   (частицы→атомы→молекулы) требует другого физ-входа (спектры вещества,
   дифракция). Сейчас звук — модель/аналог, не сама материя.
2. **Не измерено «взаимо-».** Есть наличие масштабов, нет числа межмасштабного
   **зацепления** (как один масштаб модулирует другой).
3. **Δα неустойчив на периодике** — нужен оценщик, знающий про период.
4. **Малая выборка:** один диктор, 37 звуков, без статистики между голосами.

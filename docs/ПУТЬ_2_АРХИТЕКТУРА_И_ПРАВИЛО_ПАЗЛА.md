## 4. Дыры (честно, по коду)

1. **Три разных «образа в атоме», они не сведены.**
   - Спектральный живой образ: X=время, Y=log f, палитра (`строение_атома`, полка кирпичей, `ПРАВИЛО_СБОРКИ.md` § «атомы → образ»).

   - Причина в мире: капля+удар / язык пламени / волокно ветра (`отчёты/контракт_образ_в_атоме_дождь.md`, `scripts/материя_образа.py`, `scripts/визуал_из_атомов_*.py`).
   Авторский контракт 2026-08-02 **supersede** кроп пейзажа: образ атома = частичка мироздания, создающая звук, не 2D-срез кадра. Полка природы этому контракту ещё не следует.

2. **Правила пазла нет в коде.** Есть рецепты слоёв (время/громкость) и два тупика рендера: точки и фотомонтаж. Нет закона, по которому атомы складываются в **узнаваемую** картину.

3. **Клетка как единица пазла почти не используется.** У водопада 706 атомов в одной клетке; у дождя две огромные компоненты 127 и 260. τ=0.85 на полном спектре шума даёт «почти всё связано». Для пазла клетка должна быть локальным событием (капля, удар, вспышка), а не почти-органом.

4. **Нет модуля `ядро/частички_кадра.py`** (указан в `HANDOFF_PATH2.md`). Нет `данные/алфавит_природы.json`. Нет в git `.npz` обеих полок и медиа `стихии_живые`.

5. **Ранний канон круга V3.1** (`КАНОН_ПОЛНЫЙ_КРУГ_V3.1.md`: ГЕН/фенотип, узнавание по распределениям, d₉-ε) — соседняя линия. Узнавание `приложение/общее/узнавание.js` + `ядро/метрика.py` относятся к A/кругу и **не являются** приёмкой пути 2. Не смешивать с corr моментов.

6. **Оси органа vs электрон атома.** Оси — свойства потока (`ядро/оси.py`). На полке кирпичей они копируются в электрон каждого атома; на полке природы лежат на органе. Для пазла картины оси задают **закон вещества органа** (падение, подъём, боковой поток), не картинку одного атома.

## 5. Правило пазла «атомы → узнаваемая картина»

### Формулировка (норма)

**Буква** — один полный атом: момент звука + частичка **причины** этого момента. Её можно услышать и увидеть как глиф, но она не сцена.

**Картина** — организм: игрок или рецепт ставит на общую ось времени **клетки** (локальные события) органов с полки природы. Тип клетки не равен месту: сдвиг `сдвиг_с` и слой — параметры сборки. Система рисует не точки спектра и не чужие кадры, а **материю причины** каждого атома (закон стихии органа). Узнаваемое целое рождается, когда вещества нескольких органов занимают одну сцену и один ход времени — и это целое **не совпадает** ни с одним исходным роликом.

Два канала из одних атомов, как в каноне замкнутости (`ПРАВИЛО_СБОРКИ.md`):

1. **Звук** — уже есть: overlap-add полного спектра (`из_кирпичей`), сумма слоёв (`собрать_организм`).
2. **Образ** — пазл: каждый атом кладёт на холст свой кусок вещества по `образ_причины` / закону органа; клетка держит куски одного события вместе; орган задаёт вещество; организм задаёт встречу веществ.

Игрок не рисует пиксели. Он **выбирает и ставит** готовые атомы/клетки (буквы природы) на доску организма. Система детерминированно собирает звук и картину. Успех — когда третья сторона по картине (без звука) называет ту же сцену, что задумана рецептом.

Совместимость: единица пазла = атом пути 2 (три слота); группа пазла = клетка по крестам; вещество = орган полки `библиотека_природы`; доска = организм (`СлойОргана`, тип ≠ место). Полка `библиотека_кирпичей` может давать голосовые органы в ту же доску (рецепт `вздох_а`), не меняя словарь A. Цвет по-прежнему не `freqToHue`. Спектральный живой образ (X=время, Y=log f) остаётся **слуховой проекцией** атома/буквы, не финалом картины мира.

### Как собирается (игрок / система)

1. Алфавит (буква): открыть один атом, проверить три слота и синхрон `t`. Это учебный глиф, не сдача картины.
2. Полка: взять органы стихий (дождь, ветер, гром…).
3. Доска организма: положить **клетки** (не «весь ролик») со сдвигом и громкостью — тот же объект, что `СлойОргана`, только с лимитом/маскировкой по клеткам, а не по «первые N атомов».
4. Система:
   - звук = существующий overlap-add;
   - образ = для каждого атома примитив вещества органа (`scripts/материя_образа.py` как словарь материй: капля+удар, волокно ветра, язык огня, лента водопада, вспышка→удар грома) в координатах причины, время = `t + сдвиг_с`;
   - фон нейтральный; live-видео — калибр сбоку, не содержимое атома.
5. Сдача: назвать сцену. Прототип рецепта, которого нет в сырье как целого: «лесная гроза», «костёр у реки».

Опора уже в репо (не реализовывать здесь): контракт `отчёты/контракт_образ_в_атоме_дождь.md`; рендер вещества `scripts/материя_образа.py`; траектории `scripts/визуал_из_атомов_дождь.py`. Тупик, который правилом **запрещается** считать пазлом: `собрать_образ_картины` в `scripts/собрать_картину_природы.py` (кружки по точкам кадра).

### Критерии успеха

- **Буква ≠ картина.** Один атом / один кадр / одна буква алфавита не засчитывается как картина.
- **Только атомы.** Каждый видимый примитив картины трассируется к слоту образа конкретного атома (id органа + индекс + `t`). Нет вклейки live-кадра, clean-пейзажа, HUD на фото, ручного фотомонтажа.
- **Причина, не спектр.** Финал картины — материя причины стихии, не россыпь Y=log f и не 12 RGB-точек кадра. Спектральная проекция допустима как вид «буквы», не как сдача картины.
- **Иерархия.** Клетка = одно локальное событие на холсте; орган = одно вещество; организм = встреча веществ. Рецепт не имеет права подменить клетку «случайной выборкой первых N атомов», если цель — узнаваемое событие (раскат, вспышка).
- **Тип ≠ место.** Тот же орган в другом `сдвиг_с` даёт другую картину; тип атома при этом не меняется.
- **Синхрон.** События образа и звука сидят на одной сетке `t`/`старт` (плюс сдвиг слоя). Сдвиг образа внутри атома — провал.
- **Новизна.** Целое не является ни одним исходным `video_live`. «Лесная гроза» = ветер+дождь+гром+молния, которых не было одним клипом.
- **Узнавание.** Наблюдатель (автор / слепой тест) по картине без звука называет задуманную сцену; дождь ≠ огонь ≠ гроза. Пиксельный PSNR с live **не** главный критерий (пейзаж ≠ причина).
- **Детерминизм.** Один рецепт → бит-в-бит тот же wav и тот же кадр/ролик образа. Ни нормировок слотов, ни `freqToHue`.
- **Звук не ломается.** Сборка wav по-прежнему через `из_кирпичей`; порог corr пути 2 не подменяется d₉.

### Критерии провала

- Россыпь точек / облако спектра, которое нельзя назвать сценой.
- Склейка или кроп live/clean как «картина из атомов».
- Одна буква, выданная за картину.
- Неразличимые картины разных рецептов (дождь выглядит как огонь).
- Использование типов словаря CP#2, k-means, d₉, ε_квант как судьи пазла.
- Нормировка/слияние параметров атома «чтобы картинка красиво легла».
